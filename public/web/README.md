# Assign Meter Documentation Portal

A production-style static documentation portal generated from the Assign Meter User Guide,
Privacy Policy, and Terms & Conditions.

## Run locally

Open `index.html` directly, or serve the folder with any static server.

Example:

```bash
npx serve .
```

## Included

- Responsive documentation layout
- Sidebar navigation
- Table of contents
- Full-text documentation search
- Dark/light mode
- Mobile navigation
- User Guide, Privacy Policy, Terms & Conditions
- No build step required

## Before publishing

Replace placeholder values such as `[insert date]` and `[insert support/contact email]`
in the source content with your real production information.
